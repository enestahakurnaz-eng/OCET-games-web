02Studio

Two developers, one desk's worth of opinions.

OCET GAMES is a founding team of two developers. We design, code and test everything ourselves.

Our process is simple: get a playable prototype running in days, put it in front of people, and keep only what's fun. If the core mechanic doesn't hold up with gray boxes, art won't save it.

We care about how a game feels to play and about code we can still read six months later. Both matter when the team is this small.

  • A.

    Rapid prototyping

    Small playable builds, tested early. Ideas get cut fast so the good ones get more time.

  • B.

    Gameplay feel

    Input response, timing, feedback. We tune the first ten seconds until they're worth repeating.

  • C.

    Clean engineering

    Lean builds, quick load times, and code that's easy to change when a design changes.
